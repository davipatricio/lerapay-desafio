# DESAFIO TÉCNICO - VBA System

## Requisitos

- Node.js `26.7.0`
- pnpm `11`
- Docker Desktop

## Desenvolvimento

```sh
pnpm install
docker compose up -d mysql
pnpm dev
```

- Web: http://localhost:5173
- API: http://localhost:3000/api
- Swagger: http://localhost:3000/docs

## Comandos

```sh
pnpm build
pnpm lint
pnpm format
pnpm format:check
pnpm typecheck
```
